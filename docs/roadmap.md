## Fase 1 — Fundação web

- Estrutura limpa.
- Core de regras separado.
- Inventário local-first.
- Supabase opcional.
- CI estático.

## Fase 2 — Batalha limpa

- Melhorar seleção de atacante/alvo.
- Comprar automático.
- Evitar ações inválidas.
- Registrar battle logs.
- Preparar testes de regra.

## Fase 3 — Mobile real

- Câmera nativa.
- Storage para fotos.
- Auth real.
- Build Android/iOS.
